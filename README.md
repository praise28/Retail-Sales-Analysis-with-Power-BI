# Retail Sales Dashboard — Power BI

## Project Overview

This project is an interactive **Retail Sales Dashboard** built with Microsoft Power BI. The dashboard is designed to monitor sales performance, profitability, products, locations, customers, and salespeople from a retail sales dataset.

The report presents key performance indicators (KPIs) and interactive visuals that make it easier to identify sales trends and compare performance across different business dimensions.

## Objectives

- Track overall revenue, cost, profit, and profit margin.
- Monitor premium and standard sales performance.
- Analyze revenue and profit trends over time.
- Compare revenue across states/locations.
- Evaluate product-level profitability.
- Compare sales performance across salespeople.
- Allow users to filter the dashboard by product.
- Present business performance in a clear, interactive format.

## Dashboard Features

### KPI Cards

The dashboard includes cards for:

- **Total Revenue**
- **Total Cost**
- **Profit**
- **Profit Margin**
- **Premium Sales**
- **Standard Sales**

### Interactive Visualizations

The report includes:

- **Revenue & Profit Trend** — a combination chart showing revenue and profit across the year/month hierarchy.
- **Revenue by State** — compares total revenue across states.
- **Profit by Product** — ranks products based on profit.
- **Revenue by Salesperson** — compares total revenue generated by individual salespeople.
- **Product Name Slicer** — allows users to filter the dashboard by product.

## Data Model

The Power BI report uses a model containing entities including:

- **Customers**
- **Products**
- **Locations**
- **Sales People**
- **Retail Sales**

The model is used to connect customer, product, location, sales, and transaction information for reporting.
